# Synopsis

InterPods are the new podcast format of The InterPlex. They will consist of edited compilation episodes of InterDialogues that cluster around specific topics, combining the voices of different contributors at the convergence of their expertise, tied together by contextual narration that draws links between each featured segment. InterPod publication and distribution details are discussed in [[2.6 Podcasting platforms|podcasting platforms]]. The following checklist, which can be adapted for use as a template in a [[3.8 Task management|task management program]], provides an overview of the standard InterPod production process from ideation to publication and promotion.

To help distinguish InterPods from InterDialogues, it may be advisable to develop separate assets for them, such as different intro, interval, and outro audio and a new thumbnail template. I also recommend ensuring that you can record high-quality contextual narration audio consistent with [[3.1 Audiovisual recording best practices|recording best practices]]. Let's plan for this and discuss options.

---
## 1. Planning

- [ ] Ideate potential InterPod episode topics based on published/forthcoming InterDialogues and submit for review
- [ ] Following topic approval, identify the relevant InterDialogues to be featured in the InterPod episode
	- [ ] If feasible at this stage, specify which parts of each InterDialogue should be included, in what order, and how these excerpts should be connected and contextualized
- [ ] Develop episode outline and submit for review
- [ ] Following outline approval, set target draft deadline
## 2. Production

- [ ] Use InterDialogue transcripts to identify the relevant parts of each featured InterDialogue and excerpt these parts as clips
- [ ] In Davinci Resolve, combine clips in the sequence specified in the episode outline, applying crossfaded transition intervals between clips
- [ ] Develop copy for contextual narration to introduce the InterPod episode and link the featured InterDialogue segments
- [ ] Following [[3.1 Audiovisual recording best practices|recording best practices]], record high-quality contextual narration
- [ ] Using the same audio improvement techniques specified in the [[2.4 InterDialogue production checklist]], improve narration audio
- [ ] Add improved narration audio to the working edit with transitions
- [ ] Add standard intro and outro assets
- [ ] Add timestamps based on excerpts and narration
## 3. Review

- [ ] Export the first cut and upload to YouTube as an unlisted video
- [ ] Draft title, description, and custom thumbnail for publication and submit for review
- [ ] Following final approval, mark as publication-ready
## 4. Publication and promotion

- [ ] Add all final deliverable files to the Google Drive, following [[3.3 File naming best practices]] and [[3.4 File organization best practices]]
- [ ] Schedule publication to website
	- [ ] Notify contributor when live and suggest sharing with their network
- [ ] Schedule publication to YouTube and podcasting platforms
	- [ ] The YouTube video is kept unlisted until it is launched by social media post; at that point, change it to public (or set it to premiere ahead of time) and add it to the InterPods playlist
- [ ] Schedule social media promotion
- [ ] Schedule [[2.5 Newsletter production checklist]] inclusion

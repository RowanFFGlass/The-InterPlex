# Synopsis

The InterPlex newsletter serves as a periodic communication channel for keeping subscribers informed about recent content and events, ongoing projects, upcoming events, organizational developments, fundraising initiatives, and other activities relevant to the our network. In addition to driving engagement with InterPlex content, newsletters help cultivate long-term relationships with contributors, readers, collaborators, and supporters. This checklist, which can be adapted for use as a template in a [[3.8 Task management|task management program]], provides an overview of the standard newsletter production process from planning and drafting through review and publication.

---
# 1. Planning

- [ ] Determine target publication date
- [ ] Define newsletter objectives and target audience
- [ ] Review content published since previous newsletter
- [ ] Review upcoming content, events, announcements, and organizational priorities
- [ ] Identify items to feature
	- [ ] New InterArticles
    - [ ] New InterDialogues
    - [ ] New InterPods
    - [ ] New contributors (in relation to new published content)
    - [ ] Recent events (e.g., conferences, collaborations)
    - [ ] Upcoming events
    - [ ] Contributor news and achievements (e.g., award receipt, new research)
    - [ ] Fundraising campaigns
    - [ ] Partnership announcements
    - [ ] Any other relevant developments
- [ ] Assign newsletter editor
- [ ] Establish drafting and review deadlines
# 2. Production

- [ ] Draft newsletter subject line
- [ ] Draft newsletter preview text
- [ ] Draft introduction/editor's note
- [ ] Prepare content sections
	- [ ] Featured content
	- [ ] New publications and contributors
	- [ ] Recent events
	- [ ] Upcoming events
	- [ ] Contributor news and achievements
	- [ ] Fundraising campaigns
	- [ ] Partnership announcements
	- [ ] Any other relevant content/updates
	- [ ] Call to action (if applicable)
- [ ] Draft summaries and descriptions
- [ ] Select and prepare images, graphics, or featured media
- [ ] Submit for editorial review
# 3. Review

- [ ] Editorial review
	- [ ] Verify accuracy of announcements, dates, and organizational information
	- [ ] Confirm all links function correctly
	- [ ] Review grammar, spelling, formatting, and style consistency
	- [ ] Confirm image quality and permissions
	- [ ] Confirm all featured content is correctly represented
- [ ] Incorporate editorial feedback
- [ ] Conduct final review
- [ ] Receive final editorial approval
- [ ] Mark as publication-ready
# 4. Publication and promotion

- [ ] Add final newsletter assets to Google Drive following [[3.3 File naming best practices]] and [[3.4 File organization best practices]]
- [ ] Create newsletter in email platform
- [ ] Verify subscriber list and audience segments
- [ ] Send test email
	- [ ] Check desktop formatting
	- [ ] Verify mobile formatting
	- [ ] Verify links and images
- [ ] Schedule distribution by email
- [ ] Publish newsletter archive version to website
- [ ] Ask featured contributors to engage and share
- [ ] Schedule social media promotional post
